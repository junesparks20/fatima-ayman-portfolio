# Fatima Ayman - Updated Personal Portfolio

## Technologies
HTML5 | CSS3 | Bootstrap 5 | JavaScript ES6+

## Assignment Requirements Covered

1. Semantic HTML5:
   - Home
   - About
   - Education
   - Skills
   - Experience
   - Projects
   - Achievements
   - Contact
   - Headings, lists, links, table and form

2. CSS3:
   - CSS variables
   - Selectors
   - Box model
   - Typography
   - Colors
   - Positioning
   - Flexbox
   - CSS Grid
   - Mobile-first media queries
   - Dark theme
   - Reduced-motion accessibility support

3. Bootstrap:
   - Responsive navbar
   - Grid system
   - Buttons
   - Cards
   - Table
   - Form controls
   - Alerts

4. JavaScript ES6+:
   - const/let
   - Arrow functions
   - Arrays and objects
   - map(), filter(), forEach()
   - Conditions
   - DOM manipulation
   - Event handling
   - localStorage

5. Interactive features:
   - Light/dark theme switching
   - Project filtering
   - Back-to-top button
   - Dynamic project cards
   - Client-side form validation
   - Dynamic success/error messages

## Run
Open this folder in VS Code and launch `index.html` using Live Server.

The Bootstrap and Bootstrap Icons files are loaded through CDN, so internet access is needed.

## Contact form
The form currently demonstrates client-side validation and dynamic messages.
It does not send real email. A backend or form service would be required for actual submission.
